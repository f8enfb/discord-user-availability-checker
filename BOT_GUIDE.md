# 🤖 Discord Bot для Username Checker

## Что это?

Это **Discord Bot** который работает в связке с приложением Username Checker. Бот позволяет:

✅ Проверять usernames прямо в Discord
✅ Сохранять свободные usernames
✅ Экспортировать результаты
✅ Делиться результатами с командой в Discord сервере

---

## 🚀 Быстрый старт

### Шаг 1: Запуск бота
```bash
python discord_bot.py
```
или просто кликните на **`run_bot.bat`**

### Шаг 2: Введите Bot Token
При запуске бот запросит ваш Discord Bot Token.

### Шаг 3: Используйте команды в Discord

---

## 📋 Команды бота

| Команда | Описание |
|---------|---------|
| `!setup` | Установить канал для результатов (Admin) |
| `!check_username <name>` | Проверить один username |
| `!report_available <name>` | Отчет о свободном username |
| `!report_taken <name>` | Отчет о занятом username |
| `!list_available` | Показать все свободные usernames |
| `!stats` | Показать статистику бота |
| `!clear_list` | Очистить список (Admin) |
| `!export` | Экспортировать usernames в файл |
| `!help_checker` | Показать все команды |
| `!ping` | Проверить задержку бота |

---

## 🔧 Как использовать с приложением

### Способ 1: Вручную через команды
1. Запустите **приложение** (`run.bat`)
2. Запустите **бота** (`run_bot.bat`)
3. В Discord пишите: `!check_username <сгенерированное имя>`

### Способ 2: Автоматически
Если нужна полная автоматизация, модифицируйте **main.py** чтобы отправлял результаты боту через webhook.

## ⚙️ Дополнительные настройки

### Использовать токен из переменной окружения (Рекомендуется)

Измените последнюю строку в `discord_bot.py`:

```python
import os

# Получить токен из переменной окружения
token = os.getenv("DISCORD_BOT_TOKEN")

if not token:
    print("[ERROR] DISCORD_BOT_TOKEN environment variable not set!")
    exit(1)

bot.run(token)
```

## 🐛 Решение проблем

**"Bot is already running"**
- Закройте предыдущий процесс бота
- Используйте диспетчер задач (Ctrl+Shift+Esc)

**"Invalid bot token"**
- Проверьте, что скопировали полный токен
- Создайте нового бота на Discord Developer Portal

**"Bot not responding"**
- Проверьте интернет соединение
- Убедитесь, что бот добавлен на сервер
- Перезагрузите бота

## 🎯 Интеграция с основным приложением

Чтобы основное приложение (`main.py`) отправляло результаты боту автоматически:

1. Добавьте webhook в `main.py`
2. При нахождении свободного username отправляйте запрос боту
3. Бот автоматически сохранит результат

Пример (в разработке):
```python
import requests

webhook_url = "http://localhost:5000/report_username"

# При нахождении свободного username:
requests.post(webhook_url, json={"username": "abc"})
```
